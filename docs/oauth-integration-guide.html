1. Visão Geral

O C8 Control integra diretamente com as APIs do Google e Meta para exibir métricas de campanhas, gastos e conversões no dashboard do cliente. A integração usa o protocolo OAuth 2.0 — o cliente autoriza o acesso uma única vez e os dados são atualizados automaticamente.

Arquitetura de segurança: os tokens OAuth e os client secrets nunca ficam expostos no browser. Todo o acesso às APIs externas é feito por Supabase Edge Functions (servidor), que leem os tokens armazenados no banco de dados.

5. Como os Dados são Armazenados

5.1 Tabela oauth_tokens (Supabase PostgreSQL)

CampoTipoDescrição
idUUIDIdentificador único
client_idUUIDFK para a tabela clients
providerTEXT"google" ou "meta"
access_tokenTEXTToken de acesso atual (renovado automaticamente)
refresh_tokenTEXTToken de renovação (Google) — nunca expira
expires_atTIMESTAMPTZQuando o access_token expira
ga4_property_idTEXTID da propriedade GA4 (ex: properties/123456789)
gads_customer_idTEXTID da conta Google Ads (ex: 123-456-7890)
meta_ad_account_idTEXTID da conta Meta Ads (ex: act_123456789)
Segurança: a tabela tem Row Level Security (RLS) ativado. Os tokens são acessados apenas pelas Edge Functions usando a SUPABASE_SERVICE_ROLE_KEY, que nunca é exposta ao browser.

5.2 Fluxo de dados em tempo real

Browser solicita dashboard
→
React chama supabase.functions.invoke()
Edge Function executa
→
Lê token do banco (service role)
→
Renova token se expirado
Chama API externa
→
Google/Meta retorna dados
→
Edge Function retorna JSON ao browser
React renderiza cards/gráficos
→
Cache de 5 min (React Query)

Os dados não são persistidos no banco — são buscados em tempo real a cada abertura do dashboard (com cache de 5 minutos no cliente via React Query). Isso garante que os dados estejam sempre atualizados sem sobrecarregar as APIs.

6. Configuração de Credenciais

6.1 Variáveis de ambiente do frontend (Easypanel)

Configuradas no painel do Easypanel → serviço crm → aba Environment. São IDs públicos, seguros para o browser:

VITE_GOOGLE_CLIENT_IDGoogle Cloud Console → APIs & Services → Credentials
VITE_META_APP_IDMeta for Developers → App Dashboard → App ID

6.2 Secrets do servidor (Supabase Edge Functions)

Configurados via supabase secrets set. Nunca expostos ao browser:

GOOGLE_CLIENT_IDGoogle Cloud Console → OAuth 2.0 Client ID
GOOGLE_CLIENT_SECRETGoogle Cloud Console → OAuth 2.0 Client Secret
GOOGLE_ADS_DEVELOPER_TOKENGoogle Ads → Ferramentas → API Center (conta MCC)
META_APP_IDMeta for Developers → App Dashboard
META_APP_SECRETMeta for Developers → App Dashboard → App Secret

6.3 URI de redirecionamento autorizado

Deve ser cadastrado em ambas as plataformas:

https://crm-crm.whlwlh.easypanel.host/oauth/callback

Google Cloud Console → OAuth 2.0 → Authorized redirect URIs
Meta for Developers → Facebook Login → Valid OAuth Redirect URIs

7. Edge Functions Deployadas

FunçãoEndpointResponsabilidade
oauth-exchange /functions/v1/oauth-exchange Troca o authorization code por access + refresh tokens. Salva na tabela oauth_tokens.
ga4-metrics /functions/v1/ga4-metrics Busca métricas do GA4 Data API. Renova o token automaticamente se expirado.
gads-metrics /functions/v1/gads-metrics Busca métricas do Google Ads API v16 via GAQL. Requer Developer Token.
meta-ads-metrics /functions/v1/meta-ads-metrics Busca Insights da Meta Marketing API v19. Suporta totais, por campanha e por dia.
