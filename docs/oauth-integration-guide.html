1. Overview

C8 Control integrates directly with Google and Meta APIs to display campaign metrics, ad spend, and conversions in the client dashboard. The integration uses the OAuth 2.0 protocol — the client authorizes access once and data is refreshed automatically.

Security architecture: OAuth tokens and client secrets are never exposed in the browser. All calls to external APIs are made by Supabase Edge Functions (server-side), which read tokens stored in the database.

5. How Data is Stored and Displayed

5.1 oauth_tokens table (Supabase PostgreSQL)

ColumnTypeDescription
idUUIDUnique identifier
client_idUUIDForeign key to the clients table
providerTEXT"google" or "meta"
access_tokenTEXTCurrent access token (auto-renewed when expired)
refresh_tokenTEXTRefresh token (Google) — never expires
expires_atTIMESTAMPTZWhen the access_token expires
ga4_property_idTEXTGA4 property ID (e.g. properties/123456789)
gads_customer_idTEXTGoogle Ads account ID (e.g. 123-456-7890)
meta_ad_account_idTEXTMeta Ads account ID (e.g. act_123456789)
Security: the table has Row Level Security (RLS) enabled. Tokens are accessed only by Edge Functions using the SUPABASE_SERVICE_ROLE_KEY, which is never exposed to the browser.

5.2 Real-time data flow

Google/Meta returns data

→
5-minute client-side cache (React Query)

API data is not persisted in the database — it is fetched in real time on each dashboard load (with a 5-minute client-side cache via React Query). This ensures data is always up to date without overloading the external APIs.

6. Credentials Configuration

6.1 Frontend environment variables (Easypanel)

Set in Easypanel → crm service → Environment tab. These are public IDs, safe to expose in the browser:

VITE_GOOGLE_CLIENT_IDGoogle Cloud Console → APIs & Services → Credentials
VITE_META_APP_IDMeta for Developers → App Dashboard → App ID

6.2 Server-side secrets (Supabase Edge Functions)

Set via supabase secrets set. Never exposed to the browser:

GOOGLE_CLIENT_IDGoogle Cloud Console → OAuth 2.0 Client ID
GOOGLE_CLIENT_SECRETGoogle Cloud Console → OAuth 2.0 Client Secret
GOOGLE_ADS_DEVELOPER_TOKENGoogle Ads → Tools → API Center (MCC account)
META_APP_IDMeta for Developers → App Dashboard
META_APP_SECRETMeta for Developers → App Dashboard → App Secret

6.3 Authorized redirect URI

Must be registered on both platforms:

https://crm-crm.whlwlh.easypanel.host/oauth/callback

Google Cloud Console → OAuth 2.0 → Authorized redirect URIs
Meta for Developers → Facebook Login → Valid OAuth Redirect URIs

7. Deployed Edge Functions

FunctionEndpointResponsibility
oauth-exchange /functions/v1/oauth-exchange Exchanges the authorization code for access + refresh tokens. Saves them to the oauth_tokens table.
ga4-metrics /functions/v1/ga4-metrics Fetches metrics from the GA4 Data API. Automatically renews the access token when expired.
gads-metrics /functions/v1/gads-metrics Fetches metrics from Google Ads API v16 via GAQL queries. Requires an approved Developer Token.
meta-ads-metrics /functions/v1/meta-ads-metrics Fetches Insights from Meta Marketing API v19. Supports account totals, by campaign, and by day.
